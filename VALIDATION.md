# Gate ZEC News — границы проверки

Проверяются правила новостного события, дат и первых наблюдений,
первая загрузка без исторических входов, повторы и изменение публикации,
один первичный источник / два разных издателя, отсеивание чужого актива,
слухов, предполагаемых решений и уже прошедшего движения.

Финансовые проверки: LONG/SHORT только по последующей цене, спред и объём,
исполнение по новому наблюдённому bid/ask со слиппеджем и комиссией,
нет повторов при одинаковой котировке, не продвигается состояние при
неполном funding, сохранение позиции и причин при рестарте, обработка
противоположной или изменённой новости. Проверяется настоящий HTTP UI,
локальный токен, Origin, ограничение файлов и отсутствие фиктивного бэктеста.

Финансовая модель использует exact Decimal PAPER broker прежней версии,
но это котировочная модель, не подтверждение исполнения на настоящей бирже.
Funding — опубликованная ставка × торговая цена старта расчётной минуты,
приближение к mark price. В промежутках между полученными котировками
рыночные экстремумы неизвестны.

Все технические фикстуры синтетические. Настоящие новости, котировки ZEC
и прибыльность в облаке не проверены: Gate и пять RSS-адресов возвращали
403 через прокси, в том числе после запроса расширенного доступа.
На Windows для проверки реальных адресов — CHECK_NETWORK.cmd.

Нативного Windows здесь нет. CPython Windows x64 из Astral release20261026
проверяется SHA256 до упаковки. Его запуск, Windows file locking и HKCU
Run автозапуск необходимо проверить на ПК пользователя; CHECK.cmd выполняет
офлайн-проверки. Программа не запускает реальную торговлю и не использует
секреты. Предыдущие ETH/PAPER-счета и результаты не перенесены на ZEC.


## 1.1.0: восстановление новостных каналов

203 теста прошли в Linux: 48 ZEC-тестов, включая 12 новых проверок
атрибуции издателя в Google/Bing, запрета торговли по релизам ПО,
независимого сохранения быстрой ленты и миграции старого кошелька/позиции
без сброса. Реально прочитаны zcash/zcash/releases.atom и
ZcashFoundation/zebra/releases.atom, по 10 записей. Релизы ПО исключены
из торговых сигналов. Google/Bing/Decrypt/TheBlock из облака по-прежнему
получают proxy 403; их работоспособность на Windows не заявляется.
Пользовательский лог подтверждает Gate ZEC_USDT на Windows, но не доступ
к исходным пяти лентам.

Тайм-ауты лент увеличены до 20 секунд и выводится время каждого запроса.
Новая диагностика не называет доступность только релизов готовностью
новостной торговли, пишет JSON без кошелька, токенов и финансовых данных.
Старый стандартный набор источников расширяется без изменения risk/trade;
пользовательские списки не заменяются.
