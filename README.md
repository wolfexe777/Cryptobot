# Gate ZEC PAPER Windows 1.4.0

Активный режим: цель четыре закрытые сделки/час, максимум один вход на 15-минутную свечу. Минутные сигналы импульса/разворота, удержание до 12 минут, без дневного лимита числа входов и без паузы после выхода. Фильтры и лимиты потерь имеют приоритет: сделки не гарантируются в каждой свече. Баланс 100 USDT / 5×, плановый риск 0,25% на сделку. Только PAPER; доходность не подтверждена.

Обновление: STOP.cmd → распаковать GateZecNews-update-v1.4.0.zip в прежнюю папку с заменой файлов → CHECK.cmd → START.cmd. С 1.3 сохраняются кошелёк, позиция, сделки и состояние лимитов потерь. Открытая позиция получает 12-минутный лимит удержания и может закрыться по следующей свежей котировке. Патч сохраняет settings.json/runtime, активный профиль применяется автоматически к старой конфигурации. С 1.0–1.2 сначала выполняется прежняя архивация и переход на профиль 100 USDT / 5×.

Интерфейс показывает входы и закрытия за час, цель, следующий интервал и причину ожидания. Есть переключение на прежний профиль ретеста. Полная сборка: GateZecNews-Windows-x64-v1.4.0.zip с Python x64. SHA256 приложены.

Проверки в Linux: 102 ZEC + 43 прежних Windows + 112 pytest = 257. Проверены HTTP, интерфейс, профиль и патч поверх 1.3 с сохранением настроек. Синтетический сценарий четырёх закрытий за час проверяет работу алгоритма, а не доходность на настоящем рынке. Нативного Windows и реального исторического бэктеста ZEC здесь нет. Исходники и лицензии внутри архивов; пользовательские CSV и базы отсутствуют.
