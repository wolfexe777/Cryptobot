# Gate ZEC PAPER Windows 1.4.1

Исправлена дневная блокировка после двух убытков в активном режиме: теперь это пауза 15 минут. Известные денежные стопы остаются в силе. Разворотный вход не закрывается по исходному противоположному тренду; импульсный выход требует двух полных последовательных минут подтверждения. Позиция ограничена концом её 15-минутного интервала или 12 минутами, выход только по доступной свежей котировке. Один вход на интервал, без догоняющих сделок.

Старая версия не сохраняла причину дневного запрета. Неизвестный старый запрет автоматически не снимается: кнопка «Перепроверить старую паузу» явно запрашивает свежую проверку текущих денежных порогов. Старую причину установить нельзя; известный денежный/общий стоп не снимается. При отсутствии связи ожидается новая котировка. Кошелёк, история, позиция и выключенные пользователем входы сохраняются. Добавлен CSV причин по наблюдённым интервалам; прошлые пробелы не заполняются выдуманными данными.

Обновление: STOP.cmd → распаковать GateZecNews-update-v1.4.1.zip в прежнюю папку с заменой → CHECK.cmd → START.cmd. При старой паузе используйте указанную кнопку. runtime и settings.json патч сохраняет. Полная сборка с Python: GateZecNews-Windows-x64-v1.4.1.zip.

274 технические проверки в Linux: 119 ZEC + 43 прежних Windows + 112 pytest. Проверены настоящий HTTP, UI и патч поверх 1.4.0. Нативного Windows и подтверждения доходности на реальном рынке здесь нет. Цель четыре сделки/час условна: денежные лимиты, сигналы, новости, спред и связь могут блокировать входы. Только PAPER; профиль 100 USDT / 5×. Исходники и лицензии внутри архивов; пользовательских файлов/CSV/баз нет. SHA256 приложены.
