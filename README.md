1. Остановите старую версию через STOP.cmd, распакуйте новый ZIP в отдельную папку.
2. Запустите START.cmd. Python включён. На новом счёте поставка на паузе.
3. При обновлении сохранится старое сравнение. Для смены правил нажмите
   «Пауза» → «Архивировать и начать новое сравнение» → «Запустить PAPER».
   Предыдущие кошельки и сделки остаются в базе.
4. CHECK.cmd — 28 офлайн-тестов и проверка файлов; STOP.cmd — остановка.
