# Gate ZEC PAPER Windows 1.3.0

Профиль: 100 USDT / 5×. Вход после пробоя и последующего ретеста, ограничение риска 0,25% на сделку, ATR-стоп и защитный трейлинг. Обычная торговля и новостной путь. Только PAPER; прибыльность пока не подтверждена.

Обновление: STOP.cmd → распаковать GateZecNews-update-v1.3.0.zip в прежнюю папку с заменой файлов → CHECK.cmd → START.cmd. Патч сохраняет runtime и settings.json. Старый счёт автоматически архивируется; открытая виртуальная позиция сначала закрывается по свежей котировке с учётом доступного funding, затем создаётся счёт 100 USDT / 5×. Архивные CSV доступны в интерфейсе. При недоступном Gate переход ожидает связи.

Полная сборка: GateZecNews-Windows-x64-v1.3.0.zip с Python x64.

Проверки: 86 ZEC, 43 прежних Windows, 112 корневых — 241. HTTP-интерфейс, профиль, архивы, сохранение настроек и патч поверх 1.2 проверены в Linux. Нативного Windows и бэктеста на реальной истории Gate здесь нет. SHA256 приложены. Исходники и лицензии включены в архивы; пользовательских CSV и баз нет.
