# Gate SOL News PAPER 1.0.1 — decimal contract fix

Исправлена ошибка загрузки Gate при order_size_min=0 и enable_decimal=true. SOL с множителем 1 поддерживает дробный PAPER-размер. Сохраняются бюджет маржи 5% кошелька, риск 0,25%, исходный баланс 100 USDT и плечо 5×, стратегия и интервалы.

При нулевом старом минимуме выбран консервативный PAPER-шаг 0,1 контракта. Это политика округления симулятора, не заявление точного минимального шага настоящих заявок Gate. Пример при 84,12 USDT: 0,2 SOL, маржа около 3,37 USDT. Комиссии, funding, сохранение и закрытие считают дробный размер, не число внутренних шагов. Реальных заявок нет.

Обновление ТОЛЬКО SOL 1.0.0: STOP.cmd → распаковать GateSolNews-update-v1.0.1.zip в существующую папку SOL с заменой → CHECK.cmd → CHECK_NETWORK.cmd → START.cmd. Runtime, настройки, история и кошелёк сохраняются. Не применять к ZEC. Полный ZIP с Python — GateSolNews-Windows-x64-v1.0.1.zip.

Диагностика теперь указывает ошибочное поле и endpoint. CHECK_GATE_DETAIL.cmd отдельно читает публичные contract/candles/order_book/funding и пишет gate-detail.json без ключей и счёта. Ошибка рынка больше не сопровождается сообщением о готовности новостной торговли.

151 офлайн-проверка SOL прошла в Linux, включая регрессию по предоставленному публичному контракту, дробные LONG/SHORT, риск/маржу, JSON-рестарт, funding/P&L и полную цепочку Service. Проверены настоящий HTTP, изолированный main, UI и патч поверх 1.0.0; manifest SHA256 совпадает. Нативный Windows и прибыльность не подтверждены.
