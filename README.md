[Маленькое обновление для установленной 1.0.0 — 230 КБ](https://github.com/wolfexe777/Cryptobot/raw/refs/heads/zec-news-windows-v1.1.0/GateZecNews-update-v1.1.0.zip)

[Полная Windows x64 сборка — 23,5 МБ](https://github.com/wolfexe777/Cryptobot/raw/refs/heads/zec-news-windows-v1.1.0/GateZecNews-Windows-x64-v1.1.0.zip)

В пользовательской проверке Gate ZEC_USDT работает, а пять исходных RSS
получают 403 или тайм-ауты. Обновление добавляет резервные маршруты и более
точную диагностику. Работоспособность всех маршрутов не заявляется.

## Обновление без сброса счёта

1. Выполните STOP.cmd установленного бота.
2. Распакуйте содержимое маленького ZIP **в ту папку, где лежит START.cmd**,
   с заменой файлов. В патче нет runtime и settings.json.
3. Запустите CHECK.cmd, CHECK_NETWORK.cmd, затем START.cmd.
4. Если каналы публикаций остаются недоступны, передайте файл
   `%LOCALAPPDATA%\GateZecNews\network-check.json` для диагностики.

Кошелёк, открытая позиция, сделки, риск и выключенные входы сохраняются.
Старый стандартный список пяти лент расширяется автоматически при чтении;
персональные списки не заменяются. Конфигурация риска не сбрасывается.
При установке полного ZIP в новую папку проверьте ENABLE_AUTOSTART.cmd,
если ранее включали запуск из старой папки.

## Что изменено

- Доступные в фактической проверке каналы GitHub zcash/zcash и
  ZcashFoundation/zebra: по 10 записей. Это релизы ПО, они **не дают сигнала**.
- Резервные Google News RSS и Bing News RSS для Zcash; Decrypt и The Block.
  Их доступность на пользовательском ПК нужно проверить. В облаке эти четыре
  адреса по-прежнему заблокированы proxy 403.
- Тайм-ауты лент 20 секунд. Ответ быстрой ленты сохраняется сразу, не ожидая
  медленные. Для каждой видны ошибка и время запроса.
- Google/Bing являются доставкой. Один CoinDesk напрямую и через агрегаторы
  считается одним издателем; неизвестные издатели не дают подтверждения.
- Диагностика различает доступные каналы публикаций и только релизы ПО.
  `ONLY_RELEASE_FEEDS_AVAILABLE` означает, что новостные входы пока недоступны.
  `EVENT_FEEDS_AVAILABLE` означает доступный маршрут, а не готовый сигнал.
  Для сделки всё ещё нужны новое согласованное событие и последующая цена.
- Если старая версия ещё запущена, новый START.cmd объясняет, как её остановить.

Проверка HTTPS сохранена. HTTP 403 не устраняется увеличением тайм-аута;
защита сайтов не обходится. Источники не заменяются выдуманными новостями.
