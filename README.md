# Gate SOL News PAPER 1.2.0 для Windows

Добавлены две адаптации открытых GPL-3.0 стратегий: MGM (идея взвешенных сигналов MoniGoMani, LONG/SHORT, 1m) и CombinedBinHAndCluc (две Bollinger-формулы покупок, 5m). Выбор в веб-интерфейсе активного профиля, только без позиции. MGM — новый вариант по умолчанию для старого settings.json без strategy. Прежний подтверждённый тренд доступен для сравнения.

[Источники, заявления авторов, точные коммиты, лицензии и отличия адаптации](STRATEGIES.md). Опубликованные описания прибыли оригиналов не подтверждают доходность этой версии на SOL. Никакой доходности в тестах не выдумано.

Только Gate SOL_USDT futures PAPER. Новый счёт 100 USDT / 5×; при обновлении кошелёк, история, позиции и ограничения сохраняются. Дневной лимит убытка остаётся отключён; общий стоп 1% и пауза 15 минут после двух убытков сохранены. Смена стратегии не пополняет счёт и не снимает общий стоп.

Обновление с SOL 1.0.x / 1.1.x: STOP.cmd → распаковать GateSolNews-update-v1.2.0.zip в прежнюю папку SOL с заменой файлов → CHECK.cmd → CHECK_NETWORK.cmd → START.cmd. Runtime и settings.json сохраняются. Не использовать патч для ZEC. Полный архив включает Windows Python 3.13.18 x64.

199 технических тестов в Linux; HTTP и установка патча поверх 1.1.1 проверены. Нативный Windows запуск и историческая доходность не подтверждены. Исходники app/tools/tests и GPL-3.0 входят в архивы.
