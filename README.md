## Запуск на Windows

1. Распакуйте архив целиком. Python включён.
2. **RUN_RESEARCH.cmd** загрузит свежую историю ETH_USDT с вашего ПК, выполнит
   фиксированный отбор 12 вариантов и откроет HTML-отчёт.
3. **RUN_LIQUID.cmd** — необязательное расширение на ETH_USDT/BTC_USDT/SOL_USDT.
4. **TEST_OFFLINE.cmd** повторяет сохранённый пример без сети; **CHECK.cmd**
   проверяет целостность и выполняет 43 технических теста без биржи.

Отчёт и архив результатов сохраняются в `%LOCALAPPDATA%\GateResearch`.
Архив включает только публичные котировки, funding и результаты исследования.
Существующая база GatePaper не читается и не изменяется. API-ключи не нужны,
автоматического запуска торговли нет.

Из облачной среды свежая история Gate недоступна (403). Поэтому инструмент
предназначен для загрузки и проверки на ПК пользователя. Неполная история
или funding прерывают тест; пропуски не заполняются выдуманными данными.

155 тестов прошли в Linux, из них 43 включены в Windows-пакет. Нативный Windows
в облаке не запускался. Исходники, публичный sample, протокол, лицензии и pinned
CPython x64 включены. Технические проверки не подтверждают доходность.
