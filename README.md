# GatePaper Windows — тестовая версия 1.0.0

[Скачать ZIP для Windows 10/11 x64 (23,5 МБ)](https://github.com/wolfexe777/Cryptobot/raw/refs/heads/windows-paper-v1.0.0/GatePaper-Windows-x64.zip)

Распакуйте архив целиком и запустите `START.cmd`. Python включён, API-ключи не требуются. `CHECK.cmd` — диагностика, `STOP.cmd` — остановка.

Это виртуальная торговля Gate ETH_USDT: реальные заявки не отправляются. Три стратегии, веб-интерфейс, бэктест и CSV. Исходники и лицензии включены в архив.

Прибыльность не подтверждена: проверенные исторические периоды 3 и 7 дней дали убыток. 19 технических тестов пройдены в Linux; нативный запуск на Windows не проверялся.
