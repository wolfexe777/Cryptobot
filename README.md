**В режиме hybrid обычный рыночный вход НЕ требует новости.** При пустой
ленте или сбоях RSS бот продолжает анализировать рынок ZEC_USDT Gate.
Только PAPER, реальные заявки отключены. Прибыльность не подтверждена.

## Рыночная торговля

Полные 5m свечи из пяти 1m. Тренд SMA9/21, пробой диапазона шести предыдущих
свечей либо возврат после отката, Cutler RSI14, объём от 1,1 среднего,
ATR 0,15–2%, фильтр спреда и отклонения текущей цены от сигнала. LONG/SHORT.
Каждая новая свеча обрабатывается один раз. Первый срез — прогрев без
ретроспективного входа. Исполнение по текущему bid/ask с прежними затратами.

## Роль новостей

- Совпадение с подтверждённым фоном отмечается как **«Рынок + новости»**.
- Противоположная подтверждённая новость блокирует рыночный вход и может
  закрыть открытую позицию. Фон сохраняется до 30 минут, включая сбой ленты.
- Отдельный вход **«Новость + цена»** по-прежнему ждёт реакцию после получения.
- Без подходящих статей остаётся обычный путь **«Рынок»**.
- В hybrid смена тренда по новой полной 5m может закрыть позицию.

В интерфейсе и CSV видны тип и причина входа. В настройках оставлен
необязательный `news_only`; по умолчанию применяется `hybrid`.

## Установка обновления

1. STOP.cmd — остановите предыдущий процесс.
2. Содержимое малого update ZIP распакуйте **в папку, где START.cmd**,
   с заменой файлов. `runtime` и `settings.json` патч не содержит.
3. CHECK.cmd, затем START.cmd. В интерфейсе должна быть версия 1.2.0 и
   режим «рынок + новости». Если ранее выключали входы, включите их кнопкой.

Конфигурации 1.0/1.1 без `trading` автоматически получают hybrid.
Кошелёк, открытые позиции, история и параметры риска не сбрасываются.
Старый общий стоп потерь и выключенные входы сохраняются. Для перехода
архивация счёта не требуется. Обновление не закрывает позицию при установке;
при работе новые правила могут её закрыть по рынку или новости.

223 теста прошли в Linux, из них 68 встроены в пакет. Новые 20 тестов
проверяют рыночный LONG/SHORT без статей и при ошибке RSS, отсутствие
влияния будущих свечей, блокировку новостями, сопровождение обычной позиции,
миграцию старой позиции и происхождение входа после рестарта/в CSV.
[Границы проверки](VALIDATION.md). Нативное обновление Windows и доходность
новой стратегии на настоящем ZEC здесь не проверялись.

Торговые сигналы не гарантируют сделки каждый день. Дневные/общие лимиты,
стоп, цель, размер позиции, плечо, комиссии и slippage сохранены.
Источник новостей не считается независимым фактчекером. Исторические
новости не подставляются в цены ради прибыльного бэктеста.
