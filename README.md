# Gate SOL PAPER 1.1.0 — confirmed trend and remaining-risk checks

Новый PAPER-профиль обычных входов: SMA5/15/30, согласованный наклон и импульс не меньше одного ATR, RSI 55–75 LONG / 25–45 SHORT, подтверждающая закрытая свеча. Контртрендовые range-входы отключены; SHORT остаётся при подтверждённом спаде. Новые входы только в первые пять минут четверти часа, включая новости. Максимум один вход на интервал. Частота может стать ниже четырёх в час; обязательных сделок нет.

Размер ограничен также остатком дневного и общего денежного бюджета: стоп и затраты учитываются до входной комиссии. Недостаточный остаток уменьшает размер или блокирует сделку. Начальный профиль 100 USDT / 5×, маржа до 5%, риск до 0,25%; денежные стопы 0,3% за день / 1% общий сохраняются. Дробные SOL-контракты и прежняя защита позиции сохранены.

Добавлен план риска в entry_reason_json, а также явный локальный экспорт наблюдённых котировок, минутных свечей с first_seen, funding, спецификаций и текущей PAPER-истории. Экспорт не содержит ключей/токенов и не отправляется автоматически. Исторический news-backtest не заявляется; ограничение размера помечено в truncated.

Обновление ТОЛЬКО SOL 1.0.x: STOP.cmd → распаковать GateSolNews-update-v1.1.0.zip в прежнюю папку SOL с заменой → CHECK.cmd → CHECK_NETWORK.cmd → START.cmd. Runtime, settings.json, кошелёк, история и сработавший денежный стоп сохраняются. Недостающие signals-настройки добавляются автоматически. Не применять к ZEC. Полная сборка с Python — GateSolNews-Windows-x64-v1.1.0.zip.

171 SOL-проверок в Linux, изолированный main, настоящий HTTP с JSON-экспортом, UI и патч поверх 1.0.1 проверены; SHA256 приложены. Нативный Windows и доходность новой политики не подтверждены. Это гипотеза для новых PAPER-наблюдений, не статистический оптимум: CSV закрытых сделок не содержит SMA30, пропущенных сигналов и полного пути цены. Фильтрация прошлых проигравших не считается бэктестом. Пользовательские торговые CSV, разборы, кошельки и токены в архивы не включены; исходники GPL-3.0 внутри.

В интерфейсе показан остаток до дневного денежного стопа с точностью до четырёх знаков. Причина отказа сохраняется между котировками без новой свечи.
