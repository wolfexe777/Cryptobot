# Gate SOL News PAPER 1.2.2 для Windows

Добавлен отдельный «PAPER: вход раз в 15 минут» для теста частоты. Он использует направление закрытой минуты (при равенстве — изменение за 3/15 минут), без порога MGM и фильтра минимального диапазона относительно затрат. При плоской цене, нулевом объёме, неполных/устаревших данных сигнала нет. Максимум один фактический вход в интервале и до 12 минут от входа. Комиссии и funding учитываются. Увеличение частоты не означает прибыльность.

Старый выбор MGM без selection_revision автоматически заменяется cadence. Через интерфейс можно явно вернуть MGM; новый выбор сохраняется при перезапуске. Combined и прежний тренд сохраняются. Открытая MGM-позиция сохраняет прежний анализ тренда. Баланс, история и остановки риска не сбрасываются.

Вверху показаны фактическая версия движка (/api/health) и версия страницы; при несовпадении предлагается STOP.cmd → START.cmd. Старые строки журнала помечаются историей, новые содержат версию, включая CSV.

Только Gate SOL_USDT futures PAPER, начальные 100 USDT / 5×. Дневной лимит убытка отключён, общий стоп 1% и 15-минутная пауза после двух убытков сохранены; они, ручная пауза, новости и спред могут пропускать интервалы. Четыре сделки/час не гарантированы.

Обновление с SOL 1.0.x / 1.1.x / 1.2.0–1.2.1: STOP.cmd → распаковать GateSolNews-update-v1.2.2.zip в прежнюю папку SOL с заменой файлов → CHECK.cmd → START.cmd → обновить страницу Ctrl+F5. Убедиться: движок 1.2.2, стратегия «PAPER: вход раз в 15 минут», активный профиль. Runtime и settings.json сохраняются. Не применять патч к ZEC.

217 технических тестов в Linux; HTTP, несовпадение версий в UI и установка патча поверх 1.2.1 проверены. Тест четырёх сделок на синтетическом боковом рынке изолирует частоту при отключённой серийной паузе; отдельный тест сохраняет её действие. Историческая прибыльность и нативный Windows не подтверждены. Исходники, GPL-3.0 и STRATEGIES.md включены в архивы.
