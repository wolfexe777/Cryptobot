# Gate SOL News PAPER 1.1.1 для Windows

По запросу отключён дневной лимит убытка PAPER. Сохранённая остановка с причиной daily_loss снимается при запуске, без сброса баланса, убытков, истории и позиции. Общий лимит 1% и пауза 15 минут после двух убытков в активном профиле сохранены. Стратегия и новостные условия продолжают применяться. Только SOL_USDT PAPER, реальных заявок нет.

Обновление с SOL 1.0.x / 1.1.0: STOP.cmd → распаковать GateSolNews-update-v1.1.1.zip в прежнюю папку SOL с заменой файлов → CHECK.cmd → CHECK_NETWORK.cmd → START.cmd. Runtime и settings.json сохраняются; к отсутствующему paper_limits применяется новая политика. Не использовать патч для ZEC. Полный архив включает Windows Python 3.13.18 x64.

181 технический тест в Linux, проверка миграции остановленного счёта, HTTP и установки патча поверх 1.1.0. Это не бэктест доходности; нативный Windows запуск здесь не проверен. Исходники app/tools/tests и GPL-3.0 входят в архивы.
