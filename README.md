# Gate SOL News PAPER Windows 1.0.0

Отдельная сборка SOL_USDT Gate Futures на основе исправленной ZEC 1.4.1. Начальный PAPER-счёт 100 USDT, плечо 5×, один вход на 15-минутную свечу при подходящих условиях. Максимальная маржа 5% кошелька, плановый риск 0,25% на сделку. Стоп 1,5 ATR в пределах 0,3–1,5% и не ближе 1,5× оценки затрат. Спред до 0,10%. Условия контракта и funding берутся из публичного Gate API; размеры и плечо ограничены текущими условиями. Изменение предела контрактов/плеча не выключает выход из существующей PAPER-позиции.

Новости Solana: официальный статус mainnet, Google/Bing, Decrypt, TheBlock, CoinDesk, Cointelegraph; релизы Agave/Firedancer отображаются, но не торгуются. Devnet/RPC-сбои, восстановленные инциденты и чужие активы не дают направленных сигналов. Проверка заголовков эвристическая и может ошибаться.

Установка: остановить ZEC через STOP.cmd в старой папке; при необходимости отключить его прежний автозапуск. Полный ZIP распаковать в НОВУЮ папку, выполнить CHECK.cmd, CHECK_NETWORK.cmd и START.cmd. Не распаковывать поверх ZEC. Python Windows x64 включён. Данные SOL: %LOCALAPPDATA%\GateSolNews; порт 8767; база sol-news.sqlite3. ZEC-счёт не переносится и не обнуляется.

CHECK_NETWORK.cmd показывает реальные условия контракта и пробный расчёт количества/маржи для 100 USDT / 5× без заявки и изменения счёта. Активный профиль сохраняет 15-минутную паузу после серии, дневной денежный порог 0,3% и общий 1%. Сигналы, новости, минимальный контракт, риск, затраты и связь могут уменьшить частоту ниже четырёх сделок/час.

137 SOL-проверок прошли в Linux; отдельно проверены изолированный main.py, настоящий HTTP, UI, CSV и STOP. Итоговый пакет: все SHA256 manifest совпадают, Windows PE x64 проверен, 137 встроенных тестов прошли под Linux. Нативного Windows, проверки реального Gate SOL и подтверждённой доходности/исторической оптимизации SOL здесь нет. Новые параметры — профиль для PAPER-проверки, не доказанный оптимум. Реальные заявки и ключи не используются. Исходники, GPL-3.0 и лицензии runtime включены; пользовательских CSV/кошельков нет.
