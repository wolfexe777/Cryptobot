# Gate SOL News PAPER 1.2.1 для Windows

Исправлено ожидание «Окно входа закрыто: новые сделки только в первые 5 минут интервала». Фильтр первых пяти минут удалён из MGM, Combined, прежнего тренда и общего пути новостных входов. Старый entry_window_minutes больше не применяется при чтении настроек и сохранённого счёта.

Новая позиция может удерживаться до 12 минут от фактического входа, переходя в следующий интервал. Сам переход четверти часа её не закрывает. Прежние защитные уровни и уже сохранённые дедлайны старых позиций сохраняются. Максимум один фактический вход на 15m-интервал сохраняется. В журнале видны обе границы и время последней проверки; старые строки не переписываются.

Только Gate SOL_USDT futures PAPER. Новый счёт 100 USDT / 5×; при обновлении кошелёк, история, позиции и ограничения сохраняются. Дневной лимит убытка остаётся отключён; общий стоп 1% и пауза 15 минут после двух убытков сохранены. Нужен торговый сигнал; частота и прибыль не гарантируются.

Обновление с SOL 1.0.x / 1.1.x / 1.2.0: STOP.cmd → распаковать GateSolNews-update-v1.2.1.zip в прежнюю папку SOL с заменой файлов → CHECK.cmd → START.cmd. Runtime и settings.json сохраняются. Не использовать патч для ZEC. Полный архив включает Windows Python 3.13.18 x64.

206 технических тестов в Linux; HTTP и установка патча поверх 1.2.0 проверены. Нативный Windows запуск и историческая доходность не подтверждены. Исходники app/tools/tests, описание GPL-адаптаций в STRATEGIES.md и GPL-3.0 входят в архивы.
