# GatePaper Windows 1.0.0 — тестовая версия

Windows 10/11 x64. Распакуйте архив целиком и запустите START.cmd. Python включён. API-ключи не нужны.

Виртуальная торговля фьючерсами Gate ETH_USDT, три стратегии, веб-интерфейс, бэктест и экспорт CSV. Исходники и лицензии включены. Реальные заявки не отправляются.

Прибыльность не подтверждена: проверенные исторические периоды 3 и 7 дней дали убыток. Пройдены 19 технических тестов в Linux; нативный запуск на Windows не проверялся.
